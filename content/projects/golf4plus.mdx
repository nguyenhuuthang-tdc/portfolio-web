## Project overview

**Role:** Fullstack Developer  
**Client:** Corporate client  
**Period:** October 2024 – March 2025  
**Team size:** 8

Built parts of a comprehensive indoor golf and training ecosystem consisting of an API, an admin website, a public portal, a customer booking service, and a POS system for front-desk operations.

## Responsibilities

- Designed a Node.js and Express API gateway to route secure communication across the admin, booking, and POS platforms.
- Integrated Firebase Realtime Database and WebSockets for sub-second synchronization of golf-bay availability and bookings.
- Structured MySQL relational data and optimized queries for peak-hour customer traffic.
